# Legacy: printed 155mm shell mockup (superseded 2026-08-29)

- `generate_shell_155.py` — FreeCAD generator for the Ø155 × 778 mm 3-part
  printed shell mockup (base/body/ogive) with Ø50 fuze bore
- `verify_shell_155.py` — quick geometry checks for that mockup
- `out/` — its exports (FCStd, STEP, STL segs, section preview)

**Superseded by:** the reference shell body modeled directly inside
`PGK_155mm.FCStd` (Projectile_Body + REF_Driving_Band), which is the single
source of truth for the mated kit-on-shell geometry now.
