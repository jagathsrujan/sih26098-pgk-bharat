# Legacy: two-motor PGK concept

This folder preserves the earlier exhibition concept for reference only.

It used two N20-style gear motors, two orthogonal canard shafts, face gears, and individually mounted canards. That layout is no longer the active PGK demonstrator baseline because it does not communicate the common fixed-canard carrier and de-spin architecture used in the current concept.

The active model is now generated by:

```text
cad_models/generate_pgk_155.py
```

Nothing in this folder is required for the current build. The archived FreeCAD/STL previews are retained so the earlier design can be compared without being mistaken for the current architecture.
